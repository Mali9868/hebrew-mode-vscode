מה לא נבדק כאן, ולמה:

- **תרגום אמיתי של Gemini.** לא היה מפתח API. כל זרימות התרגום נבדקו עם תשובות קבועות שמחליפות את Gemini (ראי "איך נבדק"). בדיקת המפתח עצמה כן רצה מול ה-API האמיתי של Google, עם מפתח לא תקין.
- **התוסף האמיתי של Claude Code.** אין מהסביבה הזו גישה ל-Marketplace, אז הפקודה `claude-vscode.focus` נבדקה מול תחליף. לפי התיעוד של Claude Code, הקיצור Ctrl+Esc ("Focus Input") מחליף פוקוס בין העורך ל-Claude. צריך לוודא ידנית ש-`claude-vscode.focus` רק מעביר את הפוקוס לשדה (ולא מחליף הלוך ושוב), ושהטקסט בשדה נשאר מסומן כך ש-Ctrl+V מחליף אותו.
- **מקלדות Windows ו-Mac.** הבדיקות רצו ב-Linux. ב-Windows עם פריסה עברית, Ctrl+Alt יכול לשמש כ-AltGr. ה-README מסביר איך משנים קיצור.

## פירוט הקריטריונים

### 1. טיוטה עברית מגיעה לשדה של Claude באנגלית בלי עכבר

**עובר בבדיקות. צריך אימות ידני אחד עם Claude Code.**

- ריצה ב, A1 עד A8: בשימוש הראשון, Ctrl+Alt+E פותח את הגדרת המפתח (שדה סיסמה), מציג את הודעת הפרטיות, ואחרי האישור ממשיך לבד לתרגום. האנגלית נכנסת ללוח, `claude-vscode.focus` נקרא פעם אחת, ובשורת הסטטוס מופיע "התרגום לאנגלית בלוח. Ctrl+V ואז Enter".
- ריצה ב, B1: Ctrl+Alt+Z מחזיר את הטיוטה העברית ללוח.
- כל הצעדים הם קיצורי מקלדת: Ctrl+A, Ctrl+C, Ctrl+Alt+E, Ctrl+V, Enter.
- לא אומת: ההתנהגות של `claude-vscode.focus` בתוסף האמיתי (ראי למעלה).

### 2. תשובה מועתקת מוצגת בעברית בקיצור אחד

**עובר.**

- ריצה ב, C1 עד C5: Ctrl+Alt+H פותח בצד חלון בשם "תרגום לעברית" עם התרגום. הלוח לא משתנה. החלון מימין לשמאל (`direction: rtl`), ובלוקי הקוד והקוד בשורה משמאל לימין בגופן monospace. כפתור ההעתקה שם בלוח את התרגום המדויק.
- ריצה ב, D1: גם Ctrl+Alt+E על טקסט באנגלית מציג אותו בעברית בחלון, בלי לגעת בלוח.
- צילום מסך: [חלון התרגום בתוך VS Code](evidence/panel-in-vscode.png).
- הטקסט העברי בצילום הוא תשובה קבועה של תוסף הבדיקה, לא תרגום של Gemini.

### 3. שום דבר לא נשלח ל-Claude בלי Enter

**עובר.**

- התוסף כותב רק ללוח ולחלון התרגום, ומפעיל רק את הפקודה `claude-vscode.focus`. אין בו קריאה לשום API של Claude Code ואין בו הקלדה או הדבקה.
- `policy.test.ts`: הפקודה היחידה של Claude Code בקוד היא `claude-vscode.focus`.
- `app.test.ts`, "nothing is ever sent to Claude": רשימת הפעולות של תרגום מלא היא בדיוק כתיבה ללוח וקריאה ל-focus.

### 6. התקנה מ-VSIX לפי ה-README בלבד

**עובר בבדיקות.** ה-VSIX הותקן ב-code-server עם `--install-extension`, אותה פקודה שה-README מציג (`code --install-extension`). ארבע הפקודות, שלושת הקיצורים ושורת הסטטוס נטענו (ריצה א). ה-README מכסה התקנה, הגדרת מפתח, קיצורים, פרטיות, הוספת "Always respond in English" ל-CLAUDE.md, ותקלות נפוצות. לא נבדק: התקנה דרך "Install from VSIX..." ב-VS Code לשולחן העבודה.

## החלטות מימוש שכדאי לדעת

- **קיצור אחד לשני הכיוונים:** Ctrl+Alt+E על טקסט באנגלית מציג אותו בעברית בחלון ולא נוגע בלוח. Ctrl+Alt+H על טקסט עברי רק מסביר. הכיוון נקבע לפי שיעור האותיות העבריות בפרוזה (30% ומעלה), ובטווח 10% עד 30% לפי האות הראשונה. כך "תעשה migration ב-Supabase" מתורגם לאנגלית (ריצה ב, G1).
- **שמות פקודות דו-לשוניים**, למשל "Hebrew Mode: Set API Key (הגדרת מפתח)", כדי שאפשר יהיה לחפש בשתי השפות.
- **הודעות VS Code בעברית** עטופות בתווי כיווניות בלתי נראים, כדי שמשפט עם מילים באנגלית לא יוצג בסדר הפוך. ההודעות קוצרו כך שייכנסו בשורה אחת. השוואה: [לפני](evidence/toast-before-bidi-fix.png), [אחרי](evidence/daily-quota-toast.png).
- **אם אין Flash-Lite יציב למפתח,** התוסף לא עובר לבד ל-Flash, ומציג הודעה.
